# Caso 01 — Auditoría reproducible de registros públicos de salud

`MP-DEMO-01 / SANITIZADO / SIN DATOS PERSONALES`

## Pregunta

¿Es posible convertir publicaciones oficiales heterogéneas sobre mortalidad en una base coherente, verificable y útil para detectar diferencias territoriales y problemas de calidad?

## Material de partida

Un corpus de `62` archivos originales publicados por organismos públicos, con diferencias de formato, período, cobertura y nivel de agregación.

## Trabajo realizado

- inventario y preservación de originales;
- extracción y normalización de campos;
- diccionario de datos y reglas de transformación;
- controles de duplicados, faltantes, denominadores y series temporales;
- producción de `32` tablas derivadas reproducibles;
- verificación de integridad y trazabilidad entre tablas y fuentes;
- revisión ética específica para información sobre suicidio.

## Entrega demostrativa

El paquete privado incluyó base normalizada, tablas analíticas, inventario de fuentes, manifiesto de integridad y nota metodológica. Este repositorio publica únicamente la estructura del proceso.

## Qué demuestra

<span class="evidence a">[A]</span> Capacidad de preservar y auditar un corpus documental amplio.

<span class="evidence a">[A]</span> Transformaciones trazables entre originales y resultados.

<span class="evidence b">[B]</span> Aptitud para apoyar decisiones de vigilancia y política pública, sujeta a validación con el organismo titular del dato.

## Límites

- La consistencia interna no garantiza exhaustividad del registro oficial.
- Las diferencias territoriales pueden reflejar prácticas de codificación y cobertura.
- El análisis agregado no habilita conclusiones sobre personas ni causalidad individual.

# MOTOR PAMPA

`OSINT DOCS / PUBLIC PORTFOLIO / 2026-09`

Investigación documental y análisis de datos para decisiones que exigen trazabilidad.

![Portada de la presentación Motor Pampa](presentacion/preview.png)

Motor Pampa convierte registros públicos fragmentados en productos verificables: cronologías, matrices de afirmaciones, data rooms, mapas de relaciones y análisis reproducibles. Cada afirmación fuerte conserva una ruta hacia su fuente, un grado de evidencia y una condición que podría refutarla.

## Qué contiene este repositorio

- [Metodología](metodologia/METODO.md): flujo de trabajo, evidencia, revisión y entrega.
- [Control de calidad](metodologia/CONTROL_DE_CALIDAD.md): pruebas mínimas antes de publicar o entregar.
- [Salvaguardas](salvaguardas/ETICA_Y_PUBLICACION.md): privacidad, minimización de daño y límites.
- [Investigaciones](investigaciones/README.md): Cerimedo, Cannava, IOSFA, cannabis científico, acceso a la información y suicidios, con documentos primarios y límites.
- [Casos demostrativos](casos/): tres reconstrucciones sanitizadas que muestran los formatos de entrega.
- [Servicios](comercial/SERVICIOS.md): formatos comprables y alcances de piloto.
- [Fichas comerciales](comercial/fichas/): una página por oferta.
- [Mapa de compradores](comercial/mapa_compradores.csv): 30 rutas de compra, alianza o publicación.
- [Primeros diez](comercial/primeros_10.md): secuencia priorizada y próximo paso.
- [Presentación editable](presentacion/Motor_Pampa_Research.pptx): deck institucional de once diapositivas.
- [Muestras](muestras/): estructuras sintéticas para revisar el método sin exponer casos.

## Productos

| Producto | Pregunta que resuelve | Entrega principal |
|---|---|---|
| Evidence Sprint | ¿Qué puede sostenerse hoy? | Matriz de afirmaciones, fuentes y vacíos |
| Data Room verificable | ¿Dónde está cada respaldo? | Inventario, hashes, índice y bitácora |
| Observatorio | ¿Qué cambió y qué importa? | Monitoreo periódico con alertas justificadas |
| Auditoría de datos públicos | ¿La base es consistente y reproducible? | Dataset normalizado, QA y cuaderno metodológico |

## Estándar de afirmación

- `[A]` Probado: la evidencia primaria permite publicarlo como hecho.
- `[B]` Deducción: inferencia explícita, con alternativa y límite.
- `[C]` Indicio: pista de una fuente única o interesada. No se publica como hecho.
- `[NEG]` Evidencia negativa: búsqueda documentada que no encontró respaldo esperado.

## Investigaciones identificadas

La [edición pública de las investigaciones](investigaciones/README.md) permite examinar el trabajo real detrás del portafolio. Cada línea ofrece resultados concretos, enlaces a los custodios de las fuentes primarias y preguntas todavía abiertas. La publicación no replica el acervo interno completo: algunos originales tienen datos personales, derechos de terceros o versiones superadas por rectificaciones posteriores.

## Uso seguro

Este repositorio no es un buzón para filtraciones. No envíe material sensible por issues, pull requests ni correo abierto. Para una primera conversación, abra un [issue de encuadre](https://github.com/pat031-prog/motor-pampa-research/issues/new/choose) sin nombres propios, datos personales ni archivos. El canal seguro se acuerda después de evaluar el riesgo.

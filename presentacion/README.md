# Presentación institucional

El archivo `Motor_Pampa_Research.pptx` es un deck editable de once diapositivas para reuniones comerciales y alianzas.

![Vista previa de la portada](preview.png)

## Contenido

1. Identidad y promesa.
2. Problema que resuelve.
3. Producto entregable.
4. Método.
5. Estándar de evidencia.
6. Caso de salud pública.
7. Caso de industria regulada.
8. Observatorio.
9. Servicios.
10. Rutas de mercado.
11. Piloto propuesto.

La presentación sigue el sistema visual Motor Pampa: fondo hueso, tinta, azul Motor, rojo Pampa, reglas finas y tipografía técnica. Para portabilidad del archivo se usan Arial y Courier New como sustitutos instalados de Jost, IBM Plex Sans e IBM Plex Mono.

Las notas del orador incluyen las fuentes públicas de los datos comerciales y coyunturales.

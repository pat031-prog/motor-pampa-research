# Ética, privacidad y publicación

Motor Pampa trabaja con fuentes abiertas, pero “público” no equivale a “inofensivo” ni a “libre de contexto”. La disponibilidad técnica de un dato no elimina la obligación de evaluar finalidad, proporcionalidad y daño.

## Principios

### Minimización

Se recolecta y conserva solamente lo necesario para responder una pregunta legítima. El repositorio público contiene estructuras y resultados agregados, no expedientes de trabajo.

### Identidad

Una coincidencia de nombre nunca basta para vincular personas. Se requieren atributos independientes y se documenta la posibilidad de homónimos.

### Salud y suicidio

Los análisis se presentan en forma agregada. Se evitan detalles de método, localizaciones de alta granularidad, narrativas sensacionalistas y cualquier combinación que facilite reidentificación. El producto informa políticas y calidad del dato, no perfila individuos.

### Alegaciones y derecho de respuesta

Las alegaciones se atribuyen a su fuente. Las conclusiones graves requieren corroboración proporcional, revisión especializada y oportunidad razonable de respuesta antes de publicación.

### Seguridad de fuentes

GitHub y el correo abierto no son canales de recepción para material sensible. El canal seguro se define caso por caso, después de una evaluación de riesgo.

### Retención

Cada proyecto define período de conservación, responsables de acceso y procedimiento de eliminación. No se conserva información “por si acaso”.

## Umbrales de publicación

| Tipo | Tratamiento público |
|---|---|
| Hecho documental no sensible | Publicable con cita y contexto |
| Deducción | Publicable como inferencia, con alternativa |
| Indicio no corroborado | No publicable como hecho |
| Dato personal innecesario | Se elimina o redacta |
| Material de salud identificable | No se publica |
| Acusación con riesgo jurídico alto | Revisión legal previa |

## Límites

Motor Pampa no suplanta autoridades, no determina culpabilidad, no realiza acceso no autorizado y no comercializa datos personales. Un informe describe lo que las fuentes permiten sostener en una fecha de corte.

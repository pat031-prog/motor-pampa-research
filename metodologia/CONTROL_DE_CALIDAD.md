# Control de calidad

`MP-QA / LISTA DE CIERRE`

## Integridad

- [ ] Los originales están separados de los derivados.
- [ ] El inventario cubre cada archivo entregado.
- [ ] Los hashes o tamaños se verificaron donde corresponde.
- [ ] Las transformaciones tienen insumo y salida identificables.

## Exactitud

- [ ] Fechas, nombres, unidades y jurisdicciones están normalizados.
- [ ] Los totales fueron recalculados de forma independiente.
- [ ] Se revisaron duplicados, faltantes y valores extremos.
- [ ] Las citas conducen al pasaje o fila pertinente.

## Análisis

- [ ] Cada afirmación fuerte tiene grado de evidencia.
- [ ] Las inferencias están escritas como inferencias.
- [ ] Se documentó al menos una explicación alternativa relevante.
- [ ] Se indica qué evidencia podría cambiar la conclusión.
- [ ] La ausencia de evidencia no se presenta como evidencia de ausencia.

## Riesgo

- [ ] Se revisaron homónimos e identidad.
- [ ] No se publican datos personales innecesarios.
- [ ] Se evaluó daño plausible y proporcionalidad.
- [ ] Se evitó lenguaje acusatorio no respaldado.
- [ ] Se definió necesidad de revisión jurídica o temática.

## Publicación

- [ ] El resumen coincide con el cuerpo y los anexos.
- [ ] La fecha de corte es visible.
- [ ] Los límites y fuentes faltantes están declarados.
- [ ] Los enlaces se probaron.
- [ ] El paquete público no contiene secretos, credenciales ni fuentes reservadas.

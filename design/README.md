# Sistema visual

Adaptación pública del sistema `Motor Pampa — OSINT Docs` suministrado por el titular.

## Principios

- Documento técnico, no interfaz de vigilancia.
- Fondo hueso y tinta oscura. Sin gradientes ni sombras estructurales.
- Azul para navegación y acción. Rojo Pampa para alertas y énfasis escaso.
- Bordes rectos, reglas finas y grilla de cuatro píxeles.
- Lockup tipográfico `MOTOR PAMPA` con etiqueta `OSINT DOCS`. No se inventa un isotipo.
- Jost para display, IBM Plex Sans para prosa, IBM Plex Mono para datos.
- Fechas ISO 8601, hora UTC con `Z`, hashes y códigos en mono.
- Ninguna afirmación sin fuente o grado de evidencia.

# Seguridad y recepción de información

## No enviar por GitHub

No publique en issues, pull requests ni discussions:

- datos personales o de salud;
- credenciales, tokens o claves;
- fuentes reservadas;
- documentos obtenidos bajo deber de confidencialidad;
- acusaciones no verificadas sobre personas identificables.

## Primer contacto

Use el formulario de encuadre del repositorio únicamente para describir el problema en abstracto. Motor Pampa definirá después el canal, la clasificación y la política de retención apropiados.

## Reportes de seguridad

Si detecta que este repositorio contiene material que no debería ser público, abra un issue sin reproducir el contenido sensible e indique solamente la ruta afectada.

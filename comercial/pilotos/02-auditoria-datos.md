# Modelo 02 — Auditoría de datos públicos

**Para:** equipos de salud, organizaciones de políticas públicas y redacciones que van a usar una cifra oficial para decidir, publicar o pedir explicaciones.

**Pregunta típica:** “¿Se sostiene esta comparación cuando fijamos unidad de análisis, denominador, cobertura y fecha de corte?”

## Alcance del piloto

- Una pregunta, un dataset público principal de hasta 100.000 registros y hasta dos fuentes de contraste accesibles.
- Revisión de diccionario, duplicados, valores faltantes, cambios de definición y reglas de agregación.
- Análisis descriptivo y una prueba de sensibilidad pertinente a la pregunta.
- Datos agregados o desidentificados; microdatos personales sólo tras un acuerdo de seguridad y un alcance específico.

## Entrega

Dataset normalizado si la licencia lo permite; diccionario de variables; script o cuaderno reproducible; tabla de controles de calidad; hasta tres visualizaciones funcionales; memo de 4–6 páginas con resultados, límites y preguntas abiertas. Una reunión inicial y una de lectura de resultados.

**Aceptación:** el cliente puede reproducir las tablas principales con los archivos entregados o, cuando la fuente impide redistribuirlos, con instrucciones precisas para obtenerlos. Cada comparación declara numerador, denominador y universo.

**Plazo estimado:** 12–15 días hábiles desde el brief y el acceso a la base. **Precio orientativo:** USD 1.750; una ronda de corrección o aclaración incluida.

**Fuera de alcance:** inferencia causal, validación clínica, reidentificación, integración de sistemas internos, dashboard de producción o publicación de datos de personas. Se cotizan aparte.

**Muestras del método:** [acceso a la información](../../investigaciones/acceso-informacion.md) y [serie de suicidios](../../investigaciones/suicidios.md), ambas con advertencias sobre unidades y comparabilidad.
